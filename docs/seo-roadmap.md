# Uplift Medical SEO Topical Map & Roadmap

Goal: rank for hormone/TRT intent across Tupelo, Amory, Oxford, Saltillo (and
the wider North MS market), outranking national chains on the searches they
can't serve well (women's hormones, telehealth-first, labs-based plans,
nutrition/training).

## Reality check / sequence
Local rankings = Google Business Profile + reviews + time, THEN on-site content.
Do these in parallel with the pages below:
1. Google Search Console: verify, submit sitemap, request indexing on money pages.
2. Google Business Profile: optimize, link site, collect reviews weekly.
3. NAP consistency across GBP, Facebook, Healthgrades, Yelp, directories.

## Execution order (avoid thin-content penalties: quality over volume)
1. [done] Tech SEO: canonicals, schema, sitemap, robots, fast SSR.
2. [in progress] Resources/guides system + 3 cornerstone articles.
3. Strengthen the 3 hormone service pages (longer content, FAQ schema, links).
4. Add 4-6 more guides (one per week), each linking up to a money page.
5. Add 2-3 comparison/cost commercial pages.
6. Expand location pages only as real demand appears (no doorway pages).
7. Weekly: internal linking passes, refresh titles/content, watch GSC for
   page-2 keywords (positions 10-20) and push them onto page 1.

## Cannibalization rules
- Location page = local landing ("TRT in {City}"). Service page = the offering.
  Guide = informational (symptoms/cost/how-to), never re-targets "{keyword} {city}".
- One primary keyword per page; cross-link, don't duplicate intent.

## Internal linking
- Every guide links to: the relevant service page, /qualify, /book.
- Every service page links to: relevant guides + the Tupelo location page.
- Footer: Resources hub + top guides. Nav: Resources (optional).
